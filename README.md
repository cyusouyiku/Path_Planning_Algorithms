# Path_Planning_Algorithms

## 我们在做什么

船舶管路、建筑管线以及机器人等在空间里「怎么走线」本质都是路径规划问题：既要避开障碍，又希望路程短、代价低。传统规划算法成熟可靠，强化学习则适合在规则难写全、或需要与感知联动的场景里学策略。本仓库对应我们一学期的课程/项目主线：**在统一问题设定下，把文献里的思路落地，并对比「经典规划」与「学习式规划」能各做到哪一步**。

**核心目标**可以概括成三点：读透领域相关文献，搭一个可复现的对比环境，用迭代节奏把「理解—实现—小结」跑通，而不是堆一版不好说明的代码。

---

## 时间与节奏

- **起止时间**：**4 月 11 日** 启动开发，**7 月 11 日** 结项。  
- **迭代方式**：按 **每两周一个 Sprint** 推进——每个 Sprint 有明确的交付物（例如：文献与问题界定、环境搭建、一类算法或一类实验、阶段报告等），结束时有简短回顾，再进入下一轮。

这样安排是为了把大目标拆成可检查的小块，避免到期前才集中赶工，也方便和课程或组会节奏对齐。

---

## 仓库里大致有什么

- **`sprint1/`**：前期 Sprint 的积累，以**文献与阶段资料**为主（例如路径规划、强化学习在管路/机器人场景中的应用与改进思路），为后面的实现与实验打底。  
- **`sprint2/`**：中后期 Sprint 的**实现与实验记录**（环境、多种规划与学习方法、实验脚本与文字报告等），对应「把想法做成可复现结果」那一段工作。
- **`sprint3/`**：大规模栅格（500×500 / 1000×1000）撒点环境、五种算法横向对比与 PPO 课程学习实验。
- **`sprint2/`**：100×100 基准环境与算法实现（Sprint 3 的移植来源）。

若需要看具体文件分工或如何在本机复现实验，可打开各 Sprint 目录下的 **`README.md`** 与 **`EXPERIMENT_REPORT.md`**。
