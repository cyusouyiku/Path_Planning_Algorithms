# Sprint 2：栅格路径规划算法对比实验报告

## 1. 实验目的

在统一的 **100×100 栅格环境**上，对比 **Dijkstra、A\*、RRT\*、D\* Lite** 与 **深度强化学习（PPO）** 的路径代价、计算效率与扩展量等性能指标，为船舶/建筑管路与机器人路径规划中的算法选型提供依据。

## 2. 环境与障碍说明

基础环境为 `sprint2/env.py` 中的 `GridEnvironment`。**障碍为第一版撒点**：在「地图**边界格**」「中部 **50×50 中心带** \([25,75)^2\)」与「**其余内部格**」三类候选池中，按随机权重无放回抽取若干 **整格**置障；障碍格总数约 **700–980**；起、终点各自 **5×5** 邻域内永不置障；若八连通下不可达则**整图重撒**（最多 500 次），仍失败则退化为稀疏随机整格障。同一 `seed` 得到同一地图。

移动模型为 **八连通**：直行代价 1，对角代价 \(\sqrt{2}\)，对角步满足「不切角」约束（即斜向移动时，斜格与相邻两直角格均须可通行）。

其它实现细节：与各算法共用的 `edge_cost` / `path_is_valid` / `compute_path_cost`；`matplotlib` 仅在 `render()` 中加载。

## 3. 对比算法简述

| 算法 | 类型 | 说明 |
|------|------|------|
| Dijkstra | 图最短路 | 全局最优（给定图与权），扩展量较大。 |
| A* | 启发式搜索 | 八距离下界启发，通常显著少于 Dijkstra 扩展。 |
| RRT\* | 随机采样 + 重连 | 非完备时间限下可能次优；本实验在离散栅格上实现近似 RRT\*。 |
| D\* Lite | 增量式最短路 | 静态场景下与全局最短路同价；扩展次数与实现细节、键序相关。本实现中堆内惰性删除时 **跳过已一致顶点**，避免错误地将终点 `g` 置为无穷而导致死循环。 |
| PPO | 策略梯度（on-policy） | 离散八动作；**A3C/A2C** 也可，但 **PPO** 在离散控制与 SB3 生态中默认更稳。未改 SAC/TD3（主要为连续动作设计）。 |

强化学习侧：观测量为 **局部障碍窗口 + 归一化相对目标/位置**；奖励含 **八距离势函数塑形**（拉近目标加正分）、步长惩罚、撞墙惩罚与终点大奖，以缓解稀疏奖励导致的训练失败。

## 4. 实验设置

- **硬件 / 软件**：实验在本地 Python 环境运行；经典算法为纯 CPU；PPO 使用 `stable-baselines3`（`MlpPolicy`），训练 **200 000** time steps。
- **地图与起终点**：默认 `(5,5) → (94,94)`，与 `GridEnvironment` 一致。
- **RRT\***：共 **8** 次不同随机种子，取其中**路径代价最小**的一次作为代表；表中时间为 8 次运行 wall time 的均值。
- **PPO**：训练结束后在 **30** 个回合上统计成功率与成功步长（本脚本未写入平均路径代价字段）。
- **完整原始输出**：`experiment_results.json`（由 `run_experiments.py` 生成）。

## 5. 实验结果

下表数据来自本次生成的 `experiment_results.json`（`seed=0` 运行批次）。

### 5.1 路径质量与扩展量

| 方法 | 成功 | 路径代价 | 路径长度（格子数） | 扩展量 / 采样 |
|------|------|----------|-------------------|---------------|
| Dijkstra | 是 | **131.706** | 100 | **9005** |
| A* | 是 | **131.706** | 100 | **1023** |
| D\* Lite | 是 | **131.706** | 100 | **763** |
| RRT\* | 是 | **140.636**（8 次中最优） | 111 | 采样迭代见 `extra.iterations`（约 623） |
| PPO | 是（30/30） | — | 成功回合平均 **105** 步 | — |

- **最优代价**：Dijkstra / A\* / D\* Lite 在静态同权图上一致。
- **RRT\***：8 次采样中取最优代价仍高于全局最短路。
- **PPO**：本批次在势函数塑形与 200k 步训练下 **100%** 到达终点；平均步长短于最短路步数属常见现象（策略未最小化路径长度）。

### 5.2 运行时间（Wall time，供参考）

| 方法 | 时间（量级） |
|------|----------------|
| A\* | **~0.005 s** |
| Dijkstra | ~0.036 s |
| D\* Lite | ~0.03 s |
| RRT\*（8 次均值） | ~0.185 s |
| PPO（训练） | **~61 s**（200k steps） |

说明：经典算法时间为单次规划；PPO 时间为 **离线训练**，与「查询一次最短路」的使用场景不同，不宜与毫秒级搜索直接比快。

## 6. 小结与讨论

1. **若目标是静态地图上的一次性全局最优**：**A\***（或等价的最短路实现）在代价与时间上通常最平衡；Dijkstra 代价相同但扩展更多。
2. **D\* Lite** 在静态图上与最优最短路一致，本实现中扩展量小于 Dijkstra，时间受二叉堆与惰性删除常数影响；其主要价值在 **障碍或代价变更后的增量重规划**（本实验未单独做动态场景段，可在后续作业中增加「运动障碍」子实验）。
3. **RRT\*** 在复杂高维连续空间更有优势；在 **本离散栅格**上实现为近似版本，优势不如几何连续场景明显，且存在随机性，需多次采样取优。
4. **PPO**：在势函数塑形后可达 **100% 成功率**，但路径代价仍高于最优搜索；适合 **大规模状态**、**感知噪声**或**难以建模代价**时学习策略；若必保最优，应在学得策略后再接一层全局最短路或作为 warm-start。

## 7. 复现实验

```bash
python run_experiments.py 0
```
